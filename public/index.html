Users & Roles

จัดการผู้ใช้และกำหนดสิทธิ์ (Role) — เฉพาะ Manager ขึ้นไปอนุมัติ PR ได้

ชื่ออีเมลRoleสถานะจัดการ
คำอธิบาย Role
Admin — เข้าถึงทุกส่วน + อนุมัติได้
Manager — อนุมัติ PR ได้ (Manager ขึ้นไป)
Purchasing — ฝ่ายจัดซื้อ สร้าง PR/ออก PO (อนุมัติไม่ได้)
Approver / Viewer — ดู/ใช้งานทั่วไป (อนุมัติไม่ได้)
